# 剑星修改器 v0.8

这是为腾讯应用宝 Mac 版《剑星》制作的原生 macOS 存档修改器。

## 使用方法

1. 在游戏中正常保存并完全退出《剑星》。
2. 首次打开“剑星修改器.app”，按下方“如何找到存档”的方法选择 `StellarBladeSave00.sav`；修改器会记住该位置。
3. 从左侧选择货币、材料、核心升级、技能、弹药或消耗品。
4. 勾选要修改的项目，填写目标值，点击“应用修改”。
5. 修改器会自动备份原存档、写入新值并验证 CRC32。

备份越来越多时，可进入“备份与恢复”页面单独删除某一份，或点击“清空全部备份”。删除前会再次确认，删除备份不会影响当前游戏存档。

解锁服饰时，在左侧进入“服饰解锁”，按中文名称勾选想要的服饰，然后点击“保存并解锁”。已拥有的服饰会显示为已勾选，不会重复写入。

NieR:Automata 与 NIKKE（红莲）DLC 商店的服装、发型、眼镜和配角/无人机外观已从修改器排除。这些商品必须使用游戏内的星之泪或骨头扳手正常购买；直接向库存写入会导致商店显示已拥有、无法购买，但发型库或图鉴又没有登记。请勿再用 v0.7 或更早版本解锁这些 DLC 外观。

如果已经使用旧版修改器提前解锁过这些 DLC 外观，请先退出游戏，在修改器“总览”中点击“修复 DLC 商店”。确认后，修改器会自动备份存档并完整删除检测到的 DLC 外观库存记录，但不会修改星之泪或骨头扳手。重新进入游戏后，再到对应 DLC 商店正常购买，让游戏完成自己的购买和外观库登记。已经在游戏内正常购买的 DLC 外观不要使用此修复功能。

解锁发型、眼镜/面饰、耳饰、配角服饰或无人机外观时，在左侧进入“外观解锁”：

1. 在上方选择“伊芙发型”、“眼镜/面饰”、“耳饰”、“亚当服饰”、“莉莉服饰”或“无人机外观”。
2. 勾选想要的项目，也可以使用“全选本组”。
3. 可以切换到其他分类继续勾选，待解锁数量会一直保留。
4. 点击“保存并解锁”，所有已勾选外观会一次写入并自动备份。

已拥有的外观会显示为已勾选并锁定，修改器不会删除已有发型或外观。

技能页修改的是 `SPExp` 技能经验，而不是无效的 `SPLevel` 数值。推荐填写 `99000`，应用修改后进入游戏，击败敌人获取一次技能经验，让游戏按自身规则把经验结算为技能点。不同进度需要的单点经验可能不同，因此实际增加数量以游戏结算为准。

## 如何找到存档

### 方法一：让修改器自动查找（推荐）

1. 首次打开时，如果弹出文件选择窗口，先点击“取消”。
2. 点击修改器左侧的“存档位置”。
3. 点击“自动查找应用宝存档”。
4. 如果找到，页面会显示完整存档路径，后续打开修改器无需再选。

### 方法二：手动选择

腾讯应用宝 Mac 版《剑星》的存档通常位于：

```text
~/Library/Application Support/com.tencent.yybmac.wine.engine/wine/drive_c/users/tencentyyb/AppData/Local/SB/Saved/SaveGames/
```

`~` 代表当前 Mac 用户的主目录。`Library` 是 macOS 默认隐藏的文件夹，不需要手动把它显示出来。

1. 在修改器弹出的文件选择窗口中，同时按下 `Command + Shift + G`。
2. 复制上面的完整路径，粘贴到“前往文件夹”输入框，然后按回车。
3. 进入名称为一串数字的账号文件夹，例如 `7656119xxxxxxxxxx`。每个人的数字都可能不同。
4. 选中 `StellarBladeSave00.sav`，点击“打开”。

完整路径结构类似：

```text
~/Library/Application Support/com.tencent.yybmac.wine.engine/wine/drive_c/users/tencentyyb/AppData/Local/SB/Saved/SaveGames/你的数字账号/StellarBladeSave00.sav
```

### 如果仍然找不到

- 先启动《剑星》，在游戏里正常保存一次，然后完全退出游戏。
- 确认选择的是 `StellarBladeSave00.sav`，不是 `CodexBackups` 文件夹里的 `.bak` 备份。
- `SaveGames` 下如果有多个数字账号文件夹，请选择内部 `StellarBladeSave00.sav` 修改时间最新的一个。
- 如果之后更换了应用宝容器或游戏账号，进入修改器的“存档位置”，点击“清除并重选”。

## 安全机制

- 检测到游戏正在运行时禁止写入。
- 每次修改前自动保存 `.sav.bak` 备份。
- 支持在“备份与恢复”页面一键还原。
- 普通道具只修改当前存档中实际存在的条目；服饰页可安全新增勾选的服饰记录。
- 同时更新库存数量与当前携带数量。

## 当前版本范围

v0.8 是安全存档模式，补齐非 DLC 的 19 个眼镜/面饰和 24 个耳饰，继续支持货币、材料、核心、技能经验、弹药、消耗品、116 件非 DLC 伊芙服饰，以及 14 个发型、7 件亚当服饰、6 件莉莉服饰和 8 个无人机外观的勾选解锁。NieR:Automata 与 NIKKE DLC 商店外观不会出现在修改器中。

无敌、一击必杀没有加入：它们必须连接正在运行的游戏进程实时修改，存档模式无法实现；本应用不会用无效的存档开关冒充实时功能。

如果 Steam 提示云存档冲突，请选择本地较新的存档。第一次打开如被 macOS 拦截，可在 Finder 中右键应用并选择“打开”。
