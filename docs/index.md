# sblade-explorer

《剑星》(Stellar Blade) 存档收集度分析工具：读取 Steam PC 存档，快速发现尚未收集的服装、记录、
罐子、营地等内容。**只读、离线** —— 绝不修改存档，解析与统计全部在本机完成。
