# 常见问题

## 会修改我的存档吗？

不会。程序只读取存档，解析和统计全部在内存中完成，绝不会写入存档文件。
本地设置也仅保存在本机，不会写入存档或注册表。

## 需要联网吗？

不需要。所需数据均内置于程序，运行时不会联网。
只有点击「图文攻略」「视频攻略」或搜索攻略按钮时，才会通过系统浏览器打开相应链接。

## 支持哪些平台？

目前支持 Windows 10/11。自动查找存档仅覆盖[存档位置](./save-location.md)中列出的 Windows 路径，不支持其他操作系统。

## 需要安装吗？如何升级？

不需要。便携版解压后即可使用，不会创建开始菜单快捷方式或卸载项，也不会写入注册表。
升级时，用新版 `sblade-explorer.exe` 替换旧文件即可。

## 提示缺少 WebView2 运行时怎么办？

请安装 Microsoft Edge WebView2 Evergreen Runtime，然后重新启动程序。
Windows 10/11 通常已随 Edge 安装该组件。

## 找不到存档怎么办？

界面会列出实际扫描的目录，已存在的目录可以点击「打开」在文件资源管理器中查看。
也可以点击「选择存档文件…」，直接选择任意位置的 `StellarBladeSave*.sav`。
扫描目录和文件名规则详见[存档位置](./save-location.md)。

## 为什么图鉴不计入收集进度？

目录进度只统计 13 类收集品。孽奇拔和角色图鉴根据成就别名 `Ach_Album_Unlock_*` 判断是否解锁，
在报告和界面中单独显示，因此不计入目录进度。

## 条目显示「映射待确认」是什么意思？

表示该条目的名称与别名映射置信度较低。目前共有 6 条，均为埃多斯9号营地：
由于存档中没有坐标数据，只能根据成就顺序推测别名与数据表行号的对应关系。
这不影响已获得状态的判定。如果发现条目缺失或映射错误，可以使用自定义目录库修正，
详见[数据来源与目录库](../reference/data.md#自定义目录库)。

## 如何修正缺失或错误的条目？

创建用户覆盖文件 `%LOCALAPPDATA%\sbsave\catalog.user.json`，或使用 CLI 的
`--catalog <路径>` 临时加载覆盖文件，无需重新生成目录库。文件格式见
[自定义目录库](../reference/data.md#自定义目录库)。

## 游戏更新后解析失败怎么办？

解析失败时，程序会显示明确的错误信息。请确认游戏版本与存档版本是否匹配，
不要强行使用旧版本目录库解析新版本存档。

## 支持 NG+ 和 DLC 内容吗？

支持。程序读取存档中的 `NewGamePlusPlayCount`，标注「需要二周目(NG+)」或「需要三周目(NG++)」。
DLC 和特典物品会单独标记，也可以在周目矩阵的「DLC/特典」列中对照查看，
详见[周目与收集矩阵](./collections.md#周目与收集矩阵)。

## 分类页底部为什么会提示有未关联到目录条目的已获得别名？

表示存档中有一些已获得别名无法匹配到目录库条目，可用于了解数据覆盖情况。
如需修正映射，见[自定义目录库](../reference/data.md#自定义目录库)。

## 支持装备词条（Gear）和技能（PT）吗？

v1 暂不支持，目前只统计收集物和图鉴。

## 设置保存在哪里？

侧栏底部「设置」中的外观（暗色 / 浅色 / 跟随系统）、默认搜索引擎（必应 / 百度 / 谷歌）、
打开链接的浏览器以及启动时打开的存档等偏好仅保存在本机。
攻略链接会在所选浏览器中打开；如果无法启动该浏览器，则自动改用系统默认浏览器。

## 如何使用 CLI？

参见 [CLI 文档](../cli/index.md)：`saves` 用于列出存档，`report` 用于分析并导出报告，
`dump` 用于调试，`catalog` 用于校验目录库。
