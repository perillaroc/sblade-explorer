# FAQ

## 会修改我的存档吗？

不会。程序只读存档，解析与统计全部在内存中完成，绝不写入存档文件。
本地设置只保存在本机，也不会写入存档或注册表。

## 需要联网吗？

不需要。数据内置于程序，运行时不联网；「图文攻略 / 视频攻略 / 搜索攻略」
只在你点击时由系统浏览器打开链接。

## 支持哪些平台？

Windows 10/11。存档位置探测只覆盖 [存档位置](./save-location.md) 中列出的
Windows 路径，不跨平台。

## 需要安装吗？怎么升级？

便携版，解压即用：没有安装程序、开始菜单快捷方式与卸载项，程序本体只读、不写注册表。
升级时直接用新版本替换 exe 即可。

## 提示缺少 WebView2 运行时？

请安装 Microsoft Edge WebView2 Evergreen Runtime 后重新启动程序
（Windows 10/11 通常已随 Edge 自带）。

## 找不到存档？

界面上会列出实际扫描的目录（可点「打开」在资源管理器中查看），也可用「选择存档文件…」
直接选择任意位置的 `StellarBladeSave*.sav`；目录列表与文件名规则见
[存档位置](./save-location.md)。

## 为什么图鉴不计入收集进度？

目录进度只统计 13 类收集品；图鉴（孽奇拔与角色）在报告与界面中单列显示，
以成就别名 `Ach_Album_Unlock_*` 判定是否解锁，不计入目录进度。

## 条目显示「映射待确认」是什么意思？

表示该条目的名称/别名映射置信度为低（共 6 条：埃多斯9号营地的别名→行号按成就顺序推定，无存档坐标数据）。
它不影响已获得判定；如果发现条目缺失或映射错误，可用自定义目录库修正，
见 [数据来源与目录库](../reference/data.md#自定义目录库)。

## 如何修正缺失或错误的条目？

创建用户覆盖文件 `%LOCALAPPDATA%\sbsave\catalog.user.json`，或使用 CLI 的
`--catalog <路径>` 临时附加，无需重新生成目录库；格式见
[自定义目录库](../reference/data.md#自定义目录库)。

## 游戏更新后解析失败怎么办？

解析失败时程序会给出明确错误。请确认游戏与存档版本是否匹配，
不要用旧版本的目录库强行解析新版本存档。

## 支持 NG+ 与 DLC 内容吗？

支持。程序读取存档中的 `NewGamePlusPlayCount`，标注「需要二周目(NG+)」/「需要三周目(NG++)」；
DLC/特典物品单独标记，并可在周目矩阵的「DLC/特典」列中对照查看，
见 [周目与收集矩阵](./collections.md#周目与收集矩阵)。

## 分类页底部的「另有 N 个已获得别名未关联到目录条目」是什么？

表示存档中存在未能匹配到目录库条目的已获得别名，用于反映数据覆盖情况；
如需修正映射，见 [自定义目录库](../reference/data.md#自定义目录库)。

## 支持装备词条（Gear）与技能（PT）吗？

v1 未纳入。当前只统计收集物与图鉴。

## 设置保存在哪里？

侧栏底部「设置」中的外观（暗色 / 浅色 / 跟随系统）、默认搜索引擎（必应 / 百度 /
谷歌）、打开链接的浏览器与启动时打开的存档仅保存在本机；攻略链接在所选浏览器中打开，
启动失败时自动回退到系统默认浏览器。

## CLI 在哪里用？

见 [CLI 文档](../cli/index.md)：`saves` 列出存档、`report` 分析并导出、`dump` 调试、
`catalog` 校验目录库。
