# 收集度分析

## 汇总页

左侧的「汇总」页显示存档信息和两部分进度：

- **存档信息**：SteamID、周目（含 NG+ 次数）、难度（简单 / 普通 / 困难）和游玩时间；
  存档中有地图代号和进行中主线时，还会显示当前区域与当前主线；
- **目录进度** `x/y (n%)`：显示未收集数量和已获得别名统计；
- **图鉴进度** `x/y (n%)`：单独显示，并标注「不计入目录进度」；
- **可优先收集**：本周目可直接获取的缺失条目；「离开前必收 N 件」提示仍可获得的易错过条目，
  并单独提示「已错过 N 条」。

左侧栏将内容分为两组：

- **可收集物分类**（计入目录进度，共 13 类）：纳米战衣、罐子、记录（文档/记忆棒）、密码、
  营地、发型、眼镜/面饰、耳饰、无人机外观、亚当服装、莉莉服装、设计图案、鱼类；
- **图鉴（不计入总进度）**：孽奇拔 67 条、角色 55 页。

## 分类页

点击左侧分类即可进入对应页面。每个分类页都提供：

- 顶部的「已收集 / 未收集 / 全部」筛选按钮，并显示对应的物品数量；当存档任务状态
  或当前区域可用时，还会出现「已错过 / 还来得及 / 当前区域」筛选；
- 按名称、地点或 ID 搜索；
- 分类进度条和「已收集 x/y · 未收集 z · n%」统计；
- 条目详情，点击任意条目即可查看。

部分分类采用不同的整理方式：

- **记录**：按游戏内类型分页（记忆棒、文档等），记忆棒还会按区域分组，支持展开和折叠；
- **孽奇拔**：按区域分组，支持展开和折叠。

## 条目详情

点击条目后，弹窗中会显示：

- 名称、ID、收集状态、区域和地点；
- **图鉴说明**（仅限图鉴条目）；
- **获取方式**；
- **中文攻略**：有内置链接时会显示「图文攻略」「视频攻略」；无论是否有内置链接，都提供
  「搜索图文攻略」（可在设置中更换搜索引擎）和「搜索视频攻略」（B 站）；
- **未收集原因**：例如「需要二周目(NG+)」「需要三周目(NG++)」「已错过（本存档无法再获取）」
  「可错过（仍可获得）」「NIKKE DLC（已拥有，尚未获得）」；
- **详情**：周目、DLC、易错过状态、记录类型、映射置信度和数据来源；
- 别名与备注。

## 周目与收集矩阵

纳米战衣、设计图案、耳饰、眼镜/面饰、无人机外观、亚当服装和莉莉服装支持
「周目矩阵 / 列表」两种视图。矩阵可以直观对照同一获取点在不同周目中的物品变化：

- 列为**首周目 / 二周目(NG+) / 三周目(NG++) / DLC/特典**；
- 每行代表同一个获取点；进入更高周目后，该点的物品会被替换，横向对照即可找出缺失物品；
- 状态包括：已获得、未获得、需更高周目、DLC/特典、已错过、还来得及、可错过（状态未知）和默认外观；
- 点击行可查看获取方式等详情。

## 统计规则

- 只要物品的任一别名（`aliases`）出现在存档物品集合、成就记录派生的别名或图鉴成就别名
  （`Ach_Album_Unlock_*`）中，就视为「已获得」；图鉴条目则根据成就是否解锁来判定。
- 程序读取存档中的 `NewGamePlusPlayCount`，据此标注「需要二周目(NG+)」或「需要三周目(NG++)」。
- 根据社区资料，共标记了 211 个可错过条目，涉及希雍城区（完成卢瓦底层后锁定）、
  埃多斯9号（百合进度达到 100% 后开放）以及支线任务和布告栏委托奖励。
  程序会结合存档中的任务状态，将其中 190 条判定为「已错过 / 还来得及」；没有规则或旧存档
  缺少任务数据时显示「可错过(注意节点)」，不会误报为已错过。详见
  [存档解析与判定](../reference/data.md#存档解析与判定)。
- DLC 条目默认按限定标记；在「设置 → 已拥有的 DLC」中声明后，不再按 DLC 限定阻塞。
- 共有 6 个条目的映射置信度为「低（映射待确认）」，均为埃多斯9号营地。
  分类页底部还可能提示「另有 N 个已获得别名未关联到目录条目」。

目录库共有 1007 条、16 个分类，其中包括 13 类收集品（808 条）、装备（成长区块，77 条）和图鉴（122 条）。
装备不计入收集进度，已升级为 Mk2 的装备计为已获得。
别名模型与数据来源详见[数据来源与目录库](../reference/data.md)。
