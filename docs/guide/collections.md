# 收集度分析

## 汇总页

左侧「汇总」显示存档信息与两级进度：

- 存档信息：SteamID、周目（含 NG+ 次数）、难度（简单 / 普通 / 困难）、游玩时间；
- **目录进度** `x/y (n%)`：未收集数量与已获得别名统计；
- **图鉴进度** `x/y (n%)`：单独显示，标注「不计入目录进度」。

左侧栏把内容分为两组：

- **可收集物分类**（计入目录进度，13 类）：纳米战衣、罐子、记录(文档/记忆棒)、密码、
  营地、发型、眼镜/面饰、耳饰、无人机外观、亚当服装、莉莉服装、设计图案、鱼类；
- **图鉴（不计入总进度）**：孽奇拔 67 条、角色 55 页。

## 分类页

点击左侧分类进入独立页面：

- 顶部「已收集 / 未收集 / 全部」筛选，按钮上带对应数量；
- 搜索框支持按名称、地点、ID 检索；
- 显示分类进度条与「已收集 x/y · 未收集 z · n%」；
- 点击任意条目查看完整详情。

部分分类的整理方式不同：

- **记录**：按游戏内类型分页（记忆棒、文档等），记忆棒再按区域分组、可折叠；
- **孽奇拔**：按区域分组、可折叠。

## 条目详情

条目详情弹窗包含：

- 名称、ID、收集状态、区域与地点；
- **图鉴说明**（图鉴条目）；
- **获取方式**；
- **中文攻略**：有内置链接时显示「图文攻略」「视频攻略」，并始终提供「搜索图文攻略」
  （搜索引擎可在设置中切换）与「搜索视频攻略」（B 站）；
- **未收集原因**：例如「需要二周目(NG+)」「需要三周目(NG++)」「可错过(注意节点)」；
- **详情**：周目、DLC、可错过、记录类型、映射置信度、数据来源；
- 别名与备注。

## 周目与收集矩阵

纳米战衣、设计图案、耳饰、眼镜/面饰、无人机外观、亚当服装、莉莉服装支持
「周目矩阵 / 列表」两种视图。矩阵适合对照同一获取点在多个周目的变化：

- 列为 **首周目 / 二周目(NG+) / 三周目(NG++) / DLC/特典**；
- 同一行为同一获取点，高周目会替换该点的物品，横向对比即可查漏；
- 状态图例：已获得、未获得、需更高周目、DLC/特典、默认外观；
- 点击行查看获取方式等详情。

## 统计口径

- 物品的任一别名出现在存档物品集合、成就派生别名或图鉴成就别名（`Ach_Album_Unlock_*`）中，
  即视为「已获得」；图鉴条目以成就是否解锁判定。
- 程序读取存档中的 `NewGamePlusPlayCount`，标注「需要二周目(NG+)」/「需要三周目(NG++)」。
- 可错过条目（共 211 条）按社区资料标注：希雍城区（完成卢瓦底层后锁定）、埃多斯9号
  （百合进度 100% 才开放）与支线任务/布告栏委托奖励；缺失清单显示「可错过(注意节点)」，
  详情与矩阵视图带「可错过」标记。
- 少量条目的映射置信度为「低（映射待确认）」（共 6 条，均为埃多斯9号营地）；分类页底部可能提示
  「另有 N 个已获得别名未关联到目录条目」。

目录库共 922 条 / 15 分类（13 类收集品 800 条 + 图鉴 122 条）；
别名模型与数据来源见 [数据来源与目录库](../reference/data.md)。
