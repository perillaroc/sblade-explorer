# 快速开始

只需几步即可查看收集进度：**下载 → 解压 → 启动 → 选择存档 → 查看缺失物品 → 导出报告**。
程序只读、离线运行：解析和统计全部在本机完成，绝不会修改存档。

## 1. 下载

桌面应用发布在 [GitHub Releases](https://github.com/perillaroc/sblade-explorer/releases)。
请下载 `sblade-explorer-<tag>-x86_64-pc-windows-msvc.zip`，也可以从
[最新版本页面](https://github.com/perillaroc/sblade-explorer/releases/latest)直接获取。
发布文件、命令行工具和系统要求见[下载与安装](./installation.md)。

## 2. 解压并启动

解压 ZIP 压缩包后，直接运行 `sblade-explorer.exe`。便携版无需安装，支持 Windows 10/11，
但需要系统安装 WebView2 运行时（通常已随 Edge 安装）。

## 3. 选择存档

首次启动时，程序会自动查找默认目录中的存档，并打开最近写入的主槽位。
点击顶部的「存档」下拉菜单可以切换槽位；右侧会显示文件大小和修改时间，点击「刷新」可以重新扫描。
程序会记住手动选择的存档，也可以通过「选择存档文件…」打开其他位置的存档。
如果提示未找到存档，界面会列出实际扫描的目录和可执行的操作，详见[存档位置](./save-location.md)。

## 4. 查看收集进度

左侧的「汇总」页会显示：

- 存档信息：SteamID、周目（含 NG+ 次数）、难度和游玩时间；
- **目录进度**：13 类收集品的总进度和未收集数量；
- **图鉴进度**：孽奇拔和角色图鉴单独显示，不计入目录进度。

点击左侧任意分类，即可进入对应页面。你可以按「已收集 / 未收集 / 全部」筛选，
也可以搜索名称、地点或 ID；点击条目即可查看完整详情。详见[收集度分析](./collections.md)。

## 5. 查看未收集物品

在分类页选择「未收集」，或直接搜索物品名称。点击条目打开详情弹窗后，
可以查看获取方式、中文攻略和未收集原因（如「需要二周目(NG+)」）。

## 6. 导出报告

点击右上角的「导出 JSON」或「导出 Markdown」即可保存报告。
「内容」按钮可在中文、English、双语之间切换物品信息；如需切换菜单和按钮的语言，
请前往「设置 → 界面语言」。详见[导出报告](./export.md)。
